SUTS-005 — System Character Security

The fifth SuperUnicode Technical Specification: a binary-compiled, zero-allocation schema for homograph detection and identifier security in the OpenWindows microkernel.

SUTS-005 (SCSS) is the fifth SuperUnicode Technical Specification and a core kernel primitive of the OpenWindows microkernel. It establishes a binary-compiled, zero-allocation schema for character-level security — visual homograph (confusable) detection, identifier permissibility, and script-boundary isolation — bypassing traditional text-based security databases such as Unicode’s UTS #39 (Confusables.txt, IdentifierStatus.txt) in favour of fixed-size, byte-aligned memory layouts optimized for O(1) kernel execution.

Why not a text security database

  • Compiled binary vs. text databases — UTS #39 is two UTF-8 flat files tokenized at run time; SCSS is fixed-size C structs in read-only memory, at known offsets, with no parser.
  • Zero allocation vs. heap — a user-space UTS #39 layer loads the data files into dynamic maps and per-script tables; SCSS resolves from static tables and two fixed indexes, never touching a heap.
  • Kernel primitive vs. user-space — UTS #39 targets browsers and identity libraries reading files from disk; SCSS gives the microkernel, the shell parser, and the capability path deterministic, in-band verdicts.

Dual-layer architecture

Layer Role
SUCD — offline reference Full text manifests: confusable mappings, identifier profiles, and human-readable security tables for developer tooling and user-space applications
SCSS — runtime kernel Immutable, byte-packed binary tables (scss_security_attr_t, scss_skeleton_entry_t) queried by the kernel in O(1)

Build-time tooling distils the SUCD security datasets into the tables the kernel embeds. The seeding brief named the offline layer “SUCA”; in this corpus SUCA is already the SuperUnicode Collation Algorithm (SUTS-001), so SCSS names SUCD, consistent with SUAS-009 (SIP).

Script boundary flags

SCSS encodes explicit script-isolation bitfield flags protecting system paths from cross-script injection, specifically controlling interactions between the Unicode Compatibility Bridge (0x000000–0x10FFFF) and the Native & Neography Space (0x160000–0x16FFFF). Every Native-plane codepoint carries NEOGRAPHY_MIXED and requires an isolated script context.

Compiled security metadata

A security attribute word is a compiled 32-bit bitmask; a skeleton record binds a confusable variant to a single-codepoint prototype. Codepoints are sucs_ex_char_t (64-bit), not uint32_t, so an RNUR neography lookalike in 0x00160000–0x0016FFFF and an ExtSUCS plugin codepoint above 0x7FFFFFFF survive intact.

#define SUTS_SCSS_ATTR_CAPACITY 128U
#define SUTS_SCSS_SKELETON_CAPACITY 128U
#define SUTS_SCSS_INDEX_SIZE 256U

#define SUTS_SCSS_FLAG_ALLOWED_IDENTIFIER (1u << 0)
#define SUTS_SCSS_FLAG_RESTRICTED (1u << 1)
#define SUTS_SCSS_FLAG_CONFUSABLE (1u << 2)
#define SUTS_SCSS_FLAG_NEOGRAPHY_MIXED (1u << 3)

typedef struct {
sucs_ex_char_t codepoint; /* the lookalike */
sucs_ex_char_t skeleton_codepoint; /* its prototype */
} scss_skeleton_entry_t;

typedef struct {
sucs_ex_char_t codepoint; /* the codepoint */
uint32_t flags; /* SUTS_SCSS_FLAG_* */
} scss_security_attr_t;

Identifier admissibility

scss_is_allowed_identifier is true when a codepoint carries ALLOWED_IDENTIFIER and none of RESTRICTED, CONFUSABLE, or NEOGRAPHY_MIXED. Three defaults make the predicate total over the whole space: the ASCII identifier class is allowed, SCP markers / traps / the Sentinel are restricted, and any Native-plane codepoint requires isolation. A codepoint matching none of these is not admissible — a secure identifier is closed by default.

Homographs and script mixing

A codepoint with no skeleton record maps to itself, so a plain Latin a is recognized as confusable with Cyrillic а without the Latin letter carrying a record of its own. scss_script_compatible generalizes the attack from a single character to a whole identifier, and scss_crosses_bridge_boundary tests the Bridge/Native crossing directly.

scss_script_of / scss_plane_of / scss_hash O(1)

The curated registry

The reference data holds 31 attribute records and 22 skeleton records: Cyrillic, Greek, and RNUR neography homoglyphs of Latin; invisible and control codepoints such as U+200B ZWSP, U+202E RLO, and U+FEFF BOM; and curated allowed ideographs. Skeleton prototypes collapse each script’s lookalikes onto one Latin class — Cyrillic а, Greek α, and RNUR U+160100 all map to U+0061.
