Frequently Asked Questions

Everything about SuperUnicode and its relationship to Unicode.

Compatibility

Is SuperUnicode compatible with Unicode?

Yes. Codepoints 0x000000–0x10FFFF are 1:1 with Unicode — the Unicode Compatibility Space. The guarantee is permanent: even if Unicode releases a new version or assigns new codepoints, this range still matches Unicode exactly.

Will new Unicode codepoints break SuperUnicode?

No. The bridge is defined by position, not by version. A codepoint's meaning in SuperUnicode is fixed at 0x000000–0x10FFFF; when Unicode grows, SuperUnicode simply remains in sync with the same numeric values.

Scope

Why does SuperUnicode need a 31-bit space?

Unicode covers about 1.1 million codepoints. OpenWindows uses codepoints as machine instructions too, so it reserves the System Control Plane for diagnostics and a large Native Space for its own allocations — all while keeping the entire space addressable in a single uint32_t.

What is the Sentinel?

0x7FFFFFFF. It marks end-of-stream and stops cursor advance. Nothing may be allocated at or below it; plugin codepoints start strictly above it.

Plugins & Extended

Why do plugins require a restart?

Mounting a plugin changes the active namespace, exactly like switching a runtime mode. The kernel stages the blob, returns SUCS_PLUGIN_REBOOT_REQUIRED, and only on the next boot runs the checksum gate before mounting.

What stops a malicious plugin?

The boot checksum gate (CRC32c + Fletcher-64) rejects any altered blob. Plugin partitions are OWFS only, always read-only, and quarantined plugins never mount or register ranges.

Can Base SUCS use plugin partitions?

No. Plugin Partitions are an Extended-only feature. Base SUCS uses its SuperUnicode Partition (OWFS or USFS) only for bugfix and rescue payloads.

Storage

What is OWFS?

The OpenWindows native drive filesystem. Data begins at drive offset 0x10000, integrity is CRC32c + Fletcher-64, and identity/encryption come from the ow_sec layer (ChaCha20 data-at-rest). USFS is the portable external-media variant.

Project

Where is the data?

In the versioned Public/ trees of the repositories, mirrored at modules/unicode and modules/unicode-extended, with zipped archives under Public/zipped/.

How do I write a plugin?

Use the SDK: copy template/, fill the manifest and ranges, implement sucs_plugin_entry(), then pack and verify with plugin_pack/plugin_verify. See SuperUnicode Extended.
