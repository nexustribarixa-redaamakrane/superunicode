Membership and participation

What exists today, and what may come later.

SuperUnicode is an experimental, developer-led open-source project. It does not have a formal membership program, a consortium organization, a member portal, a voting system or a membership approval process.

Those things are possible future directions, not current arrangements. If the project develops them, the details will be documented here after they exist.

Take part without joining

You do not need to be a member to use, review or contribute to SuperUnicode. Participation happens through the project’s public repository:

  • Explore the standard, the technical reports and the machine-instruction database.
  • Review the source code and documentation in the GitHub repository.
  • Report a problem or ask a question in the issue tracker.
  • Contribute by following CONTRIBUTING.md and opening a pull request.

Feedback on the specifications and the implementation is useful even if you do not write code. Reports about unclear documentation, missing tests and behavior that does not match the specifications are especially welcome.

A note on the Consortium pages

References elsewhere on this site to a SuperUnicode Consortium describe a possible direction, not an organization that currently exists. The project has no formal organization, member registry, voting procedure or allocation authority today.

In short: no membership is required, and none is currently offered. Use the project, review it and send feedback through the public repository.
