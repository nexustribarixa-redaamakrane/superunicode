# SUTN-002 - Unicode Analog Crosswalk

**Standard ID:** SUTN-002
**Status:** 0.1.0 - Published
**Scope:** Informative mapping between SuperUnicode document families and Unicode UAX, UTS, and UTR roles
**Applies To:** readers comparing SuperUnicode architecture documents with Unicode publications
**Last Updated:** 2026-11-02

## 1. Purpose and Non-Normative Status

This note is non-normative. Following it does not establish conformance to
SuperUnicode, any SUAS standard, or any SUTS specification.

The note records useful analogies between the two corpora. An analogy explains
purpose and lineage; it does not assert identical algorithms, data, scope, or
compatibility. The cited SuperUnicode document remains the only source for its
own requirements.

## 2. Audience and Prerequisites

This note is for standards readers, implementers, and reviewers familiar with
the [SUAS index](../suas/INDEX.md), [SUTS index](../suts/INDEX.md), and
[SUTR index](../sutr/INDEX.md). Read the cited documents before relying on an
analogy.

## 3. Crosswalk

| SuperUnicode role | Typical Unicode analogue | Examples |
|---|---|---|
| SUAS architecture standard | UAX-like normative architecture annex | SUAS-001 SDF, SUAS-006 STS, SUAS-012 SUCD |
| SUTS technical specification | UTS-like optional technical specification | SUTS-001 SUCA, SUTS-005 SCSS, SUTS-012 SCTE |
| SUTR technical report | UTR-like informative report | SUTR-0 SUCS, SUTR-7 SUCEM, SUTR-014 OKTP |
| SUTN technical note | Project guidance, not a Unicode standards family | SUTN-001 and this note |

## 4. Limits of the Analogy

Unicode publication families and SuperUnicode families have different
governance, scope, and conformance rules. In particular, SUTS documents bind
only when claimed, while SUTR and SUTN documents are informative.

## 5. Relationship to Normative Documents

This note summarizes [docs/INDEX.md](../INDEX.md). SUAS, SUTS, and SUTR
requirements and meanings are defined only by their own documents.

## 6. Lifecycle and Review

Review every 12 months and whenever a family definition changes. Withdraw this
note when the crosswalk becomes misleading; do not silently repurpose it.

UTR means Unicode Technical Report.
