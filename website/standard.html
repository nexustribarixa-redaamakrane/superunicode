The SuperUnicode Standard

Base SUCS — a 31-bit character set of codepoints, machine instructions and a permanent Unicode bridge.

The Base SuperUnicode Character Set (SUCS) occupies the codepoint space 0x00000000–0x7FFFFFFF (31 significant bits, held in a uint32_t SUCS_CP). Every codepoint is an atomic unit, and codepoints are grouped into an explicit hierarchy:

The hierarchy

  1. Territory — 16 zones (256 MiB)
  2. Zone — 16 districts (16 MiB)
  3. District — 16 planes (1 MiB)
  4. Plane — 65,536 codepoints (64 KiB)
  5. Range — a declared contiguous allocation
  6. Block — a named run of codepoints
  7. Codepoint — the atomic unit

The three spaces of Base SUCS

Unicode Compatibility Space

0x000000 – 0x10FFFF

Planes 0 and 1. Every value is 1:1 with the same-numeric Unicode codepoint — permanently. If Unicode publishes a new version or assigns new codepoints, this space still matches: compatibility is a frozen guarantee, not a snapshot.

System Control Plane (SCP)

0x110000 – 0x11FFFF

Plane 0x11. Non-printable codepoints are machine instructions that do not advance the cursor. Hosts the BANcode Registry of diagnostic instructions:

  • 0x0011A000–0x0011A7FF — BANcode (B+) — halt/rollback diagnostics
  • 0x0011A800–0x0011ABFF — WARNcode (W+) — warn-and-continue
  • 0x0011AC00–0x0011ADFF — COMcode (C+) — communication
  • 0x0011AE00–0x0011AEFF — SOFTcode (S+) — soft-fault

Native SuperUnicode Space

0x120000 – 0x7FFFFFFF

Planes 0x12–0x7FF. The open field for OpenWindows' own codepoints. The top of the space is reserved:

  • 0x7FFFFFF0–0x7FFFFFFE — Traps (raise the instruction stream into diagnostics)
  • 0x7FFFFFFF — Sentinel (end-of-stream; not an allocation)

Nothing may be allocated at or below the Sentinel — plugin codepoints begin strictly above 0x7FFFFFFF.

The hierarchy at work

Address arithmetic makes the hierarchy cheap and total. For example, the BANcode registry block lives in territory 0, zone 0, district 1, plane 0x11, at the intersection of the System Control Plane's diagnostic ranges — all derived by shifting CP >> 16/20/24/28.

SUCS_CP 0x0011A000
plane 0x0011 // System Control Plane
district 0x0011 >> 4 = 0x01
zone 0x0011 >> 8 = 0x00
territory 0x0011 >> 12 = 0x00
