SUCA collation

The ordering contract for SuperUnicode strings.

  • Default binary order — codepoint-ascending, Sentinel last. Cheap, deterministic, universal.
  • Unicode Bridge ordering — the compatibility space sorts by its bridged Unicode codepoint.
  • Control plane ordering — SCP instructions sort after every printable allocation.
  • ExtUCA — Base region first, then plugin regions by registration sequence.

Formalized in SUTR-2. Data: collation/SUCA.txt and collation/ExtUCA.txt.
