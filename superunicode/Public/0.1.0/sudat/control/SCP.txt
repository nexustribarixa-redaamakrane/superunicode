# SCP.txt - SuperUnicode Control Plane layout (starter)
# The control plane is the machine-instruction registry of Base SUCS.
PLANE         00110000-0011FFFF   Control
RESERVED      00110000-0011A000   Future registry blocks
BANCODE       0011A000-0011A7FF   Fatal unrecoverable errors (crashes)
WARNCODE      0011A800-0011ABFF   Warnings but non-fatal
COMCODE       0011AC00-0011ADFF   Reports of operations/communications; successes
SOFTCODE      0011AE00-0011AEFF   Soft errors
RESERVED      0011AF00-0011FFFF   Future control-plane blocks
