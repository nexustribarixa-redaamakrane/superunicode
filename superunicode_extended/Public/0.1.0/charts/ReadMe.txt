# charts/ - Extended code charts.

# 0.1.0 charts cover the plugin ranges recorded in the registry; generated
# from each plugin's names/ and props/ tables at release time.
#
# This folder also mirrors the Unicode 18.0.0 reference chart set for
# convenience: 368 *.pdf files, flat, with Unicode's exact filenames
# (U0000.pdf, U4E00.pdf, ...), sourced from
# https://www.unicode.org/Public/18.0.0/charts/PDF/
#
# The mirror is NOT a claim that plugin codepoints are Unicode codepoints:
# plugin ranges (0x80000000+) and the Native plane have no Unicode chart.
# Plugin-specific charts are still generated from the recorded plugin data.
#
# Unicode charts are © Unicode, Inc.; see https://www.unicode.org/copyright.html
# for the Terms of Use. Do not edit the PDFs - re-import from the source above.
